Installation
1. Extract everything in the zip to a permanent folder, for example
   C:\Program Files\@APP@ or D:\EPIC EDITORS\@APP@
   (right-click the zip > "Extract All…").
2. Run "@APP@.exe".
3. The first time, Windows may show "Windows protected your PC" (the program is not
   digitally signed). Click "More info" > "Run anyway".
4. Optional: right-click "@APP@.exe" > "Show more options" > "Send to" >
   "Desktop (create shortcut)".

Nothing else is installed. To uninstall, delete the folder.
@LANG@

Requirements: Windows 10 or 11, 64-bit.
